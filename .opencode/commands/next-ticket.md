Ты работаешь по тикетам Second Brain.

Frontier — открытые `ready-for-agent` issue, у которых все blocked-by закрыты:

!`.opencode/scripts/frontier.sh`

Правила:

- Если передан номер (`$ARGUMENTS`), работай с ним, но только если все его блокеры закрыты.
- Иначе выбери тикет с наименьшим номером из frontier.
- Не бери `ready-for-human`.
- Не начинай тикет с открытыми блокерами.
- Не трогай parent #1.
- Перед началом назначь issue на `@me`, чтобы параллельная сессия не взяла тот же тикет. Если issue уже назначен на другого, не бери его.

Порядок работы:

1. Прочитай issue: `gh issue view <n> --json number,title,body,labels,comments,assignees`.
2. Сверь acceptance criteria с текущим кодом. Если в репозитории ещё нет коммитов, сначала предложи пользователю initial commit; не коммить `.idea/` и секреты.
3. Вызови Skill `implement` с ссылкой на тикет. Дальше следуй его инструкциям: TDD на согласованных seam'ах, регулярный typecheck и тесты, полный прогон в конце, code-review.
4. Открой PR с `Closes #<n>` (или закоммить в main и закрой issue, если PR не используется).
5. В PR опиши, что сделано и как проверено. Если тикет не завершён, оставь его открытым и напиши статус.

Не закрывай issue, пока acceptance criteria не выполнены и проверки не прошли.
