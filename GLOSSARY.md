# Second Brain

Общая память для агентов, которые получают доступ по токену. OpenCode и Jarvis — первые интеграции, но не границы продукта.

## Language

**Память (Memory)**:
Общая база знаний, в которую агенты пишут по команде и из которой читают поиском.
_Avoid_: база OpenCode, база Jarvis

**Агент (Agent)**:
Программа, которая пишет или читает память по токену. OpenCode, Jarvis, Claude и Cursor — примеры агентов, а не типы памяти.
_Avoid_: источник, интеграция, плагин

**Клиент (Client)**:
Именованный доступ агента к памяти: токен, scope, источник и статус. Один агент может иметь несколько клиентов, например по одному на машину или окружение.
_Avoid_: пользователь, приложение

**Токен (Token)**:
Секрет клиента, который показывается один раз при выпуске и дальше хранится только в виде хеша.
_Avoid_: пароль, ключ доступа

**Источник (Source)**:
Уникальная метка клиента, которая попадает в его записи и используется для фильтрации. У активных клиентов источники не повторяются.
_Avoid_: kind, тип клиента, плагин

**Scope**:
Разрешение токена на конкретное действие: чтение, запись, управление или доступ к приложению.
_Avoid_: роль, право

**Remember**:
Операция, которой агент сохраняет память по команде пользователя.
_Avoid_: ingest, загрузка

**Ingest**:
Приём нормализованных сессий OpenCode через spool-бандлы. Это адаптер OpenCode, а не общий путь записи для всех агентов.
_Avoid_: remember, память

**MCP**:
Основной протокол удалённого доступа агентов к памяти: инструменты `remember`, `search`, `get_record`, `list_projects`, `stats`.
_Avoid_: API, плагин

**Запись (Record)**:
Одна единица памяти с карточкой и исходным текстом.
_Avoid_: документ, сообщение

**Карточка (Card)**:
Структурированное представление записи: заголовок, краткое содержание, вопросы, ключевые слова и атомы.
_Avoid_: заметка, summary

**Проект (Project)**:
Группа записей, объединённых местом работы или темой.
_Avoid_: папка, репозиторий
